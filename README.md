# Maquina-expendedora-de-caf-
Simulación de una máquina expendedora de café 

Productos 
Capuchino  Valor = 4,000  / Stock = 15
Café americano Valor = 3,000 / Stock = 15
Mocachinno Valor = 5,000 / Stock = 15
Chocolate  caliente Valor = 4,000 / Stock = 15
Leche caliente Valor = 4,000 / Stock = 15

Entradas
Selección de producto
Cantidad de dinero que se ingresó
Producto solicitado

Salidas
Producto seleccionado
Valor de las vueltas
Mensaje de error si el dinero es insuficiente
Mensaje si el producto esta agotado
Mensaje de que la compra se realizó con éxito

Reglas de negocio: 
- La máquina ofrece cinco productos.
- Cada producto tiene un stock limitado.
- No se puede comprar un producto que está agotado.
- El dinero que se ingresa debe ser igual o superior al valor del producto.
- Si el dinero es suficiente, se entrega y se calculan las vueltas que toca devolver.
- Si el producto no tiene stock, sale mensaje de error.
- Si el dinero es insuficiente, mensaje de error y no se entrega el café.
- Si el cliente elige cancelar la compra, el dinero es devuelto.
